# Poker Rules

- [Policy catalogue](POLICY_CATALOGUE.md): normative rules, configurable table policies, and executable examples

Rules documents define product behaviour. Architecture decision records define how that behaviour is implemented.

Status vocabulary:

- `Normative`: part of the selected No-Limit Texas Hold'em rules baseline
- `Accepted`: product policy approved for implementation
- `Proposed`: recommended product default awaiting approval
- `Configurable`: an explicit table or tournament setting with a documented default
- `Open`: insufficiently decided for implementation

Changes that affect chips, action rights, or pot eligibility require an updated example and regression test.
